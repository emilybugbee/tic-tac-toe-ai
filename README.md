# tic-tac-toe-ai

An unbeatable Tic-Tac-Toe AI developed in C++ for my Data Structures course at Santa Monica College.

## What I Built
- Implemented a game tree to generate possible future game states
- Evaluated game states to determine optimal moves
- Implemented and debugged game-tree functionality
- Used recursion, pointers, and data structures to model gameplay

## Technologies
C++ · Data Structures · Algorithms · Game Trees · Recursion

## Course Context
Developed as a CS 20A course project at Santa Monica College. Project specifications and portions of the starter code/scaffolding were provided by my instructor, Nathan Greenfield. My implementation was completed as part of the assignment.
